# Créer des hyperliens dans les tableaux à structure libre

Découvrez comment créer des hyperliens pour un ou plusieurs éléments de dimension, afin de les rendre cliquables dans un tableau à structure libre d’Analysis Workspace. Vous pouvez créer des liens hypertexte pour les éléments de dimension qui comportent des valeurs d’URL, des URL personnalisées pour les éléments de dimension qui comportent des valeurs non-URL ou pour les URL personnalisées dynamiques pour plusieurs éléments de dimension à l’aide de variables. Pour consulter la documentation détaillée, consultez [Création de liens hypertexte pour les dimensions d’un tableau à structure libre](https://experienceleague.adobe.com/en/docs/analytics/analyze/analysis-workspace/visualizations/freeform-table/freeform-table-hyperlinks).
